# Pet Choice India Frontend

## Overview
Pet Choice India is a headless e-commerce platform designed to provide a seamless shopping experience for pet owners in India. This frontend application is built using Next.js, React, and TypeScript, ensuring a modern and efficient user interface.

## Project Structure
The frontend is organized into several key directories:

- **pages/**: Contains the main application pages, including the homepage, product details, cart, and admin dashboard.
- **components/**: Reusable React components such as headers, footers, and product cards.
- **hooks/**: Custom React hooks for managing state and fetching data.
- **styles/**: CSS files for styling the application.
- **utils/**: Utility functions for API calls and authentication.

## Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm (Node package manager)

### Installation
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/pet-choice-india.git
   cd pet-choice-india/frontend
   ```

2. Install dependencies:
   ```
   npm install
   ```

### Running the Application
To start the development server, run:
```
npm run dev
```
The application will be available at `http://localhost:3000`.

### Building for Production
To create an optimized production build, run:
```
npm run build
```
Then, to start the production server:
```
npm start
```

## Features
- **Homepage**: Showcases featured products, categories, and an Instagram feed.
- **Product Page**: Displays product details, images, variants, and reviews.
- **Cart & Checkout**: Secure integration with Razorpay/PayU for payment processing.
- **Admin Dashboard**: Manage products, orders, and vendors with a user-friendly interface.
- **Store Locator**: Interactive map for locating stores.
